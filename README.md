### `whoami`

I build AI agents and automated systems — from idea, to working prototype, to shipped product. Most of my recent work sits at the intersection of **agent harnesses, tool-use safety, and memory-backed reasoning**: giving agents real tools, sandboxing what they run, and pausing them before anything irreversible happens.

- 🏗️ Currently building agent tooling that pairs LLM reasoning with human-in-the-loop approval on high-stakes actions
- 🧠 Interested in agent memory, MCP servers, and evaluation harnesses
- 🎯 Focusing on shipping fast, then hardening what survives contact with real use

### `pinned_work`

|---|---|
| **[Agent-Harness-](https://github.com/aiwithrajan/Agent-Harness-)** | Hackathon build for The Agent Harness Hackathon. An agent looks up an order via a real MCP tool, proves a duplicate charge by running JS in a sandboxed `node:vm`, then **pauses** — the refund only fires after a human stamps approval. |
